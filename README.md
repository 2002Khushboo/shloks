# श्रीमद्भगवद्गीता — Shloks

A simple web application for reading Bhagavad Gita shlokas in a clean, open-book style interface.

The application currently uses the [Vedic Scriptures API](https://vedicscriptures.github.io/) to retrieve Bhagavad Gita verses, Sanskrit text, transliteration, Hindi meaning, and commentary.

## ✨ Features

- 📖 Open-book style reading interface
- 🕉️ Sanskrit shloka display
- 🔤 Sanskrit transliteration
- 🇮🇳 Hindi meaning
- 📚 Hindi भावार्थ / commentary
- 📅 Daily shloka selection
- 🔄 Daily progression through the Gita
- 📱 Responsive web interface
- 🌐 Designed to be deployed using GitHub Pages

## 🛠️ Tech Stack

- React
- Vite
- JavaScript
- CSS
- Vedic Scriptures API
